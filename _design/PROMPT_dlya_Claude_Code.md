# Задача: перенести дизайн GAZ GAME v6.4 в рабочую игру

## Контекст
В корне проекта лежит папка `_design/` с эталоном дизайна:
- `_design/gaz-design-v6-4.html` — интерактивный макет (один файл, открывается в браузере). Это ЭТАЛОН ВНЕШНЕГО ВИДА.
- `_design/bg.mp3` — главная музыка игры (Naphi — TipToes).
- `_design/etalon/*.png` — 14 скриншотов эталона по экранам (390×844).

Рабочая игра (этот проект) — источник ЛОГИКИ: игры, тесты, вопросы, подсчёт, итоги, сохранения, навигация, данные.

**Цель:** игра должна выглядеть и ощущаться как макет — до мелочей (цвета, шрифты, тени, текстуры, анимации, звуки, музыка, заставка), а работать — как сейчас.

## Жёсткие правила
1. Логику, данные, тексты вопросов/тестов/итогов, роутинг и API НЕ менять. Меняется только слой отображения (разметка, стили, ассеты, анимации, звук).
2. НЕ копировать JS/CSS макета целиком: он собран из ~50 наслоённых правок (`!important`, переопределения функций). Макет — образец, а не код для вставки. Из него можно брать SVG, градиенты, тени, keyframes, тексты оформления.
3. Сначала разведка и план, потом код. Работать по экрану за раз, после каждого — проверка, что игра работает как до изменений.
4. Перед стартом — отдельная git-ветка `design-v6-4`, коммит после каждого этапа.


## ВАЖНО: в макете есть НОВЫЕ ФУНКЦИИ, которых, скорее всего, нет в игре
Это не только оформление — это механики, их нужно ДОБАВИТЬ (логику писать по образцу макета). На Этапе 0 отметь для каждого пункта: «есть в игре / нет / частично».

**Главный стол**
- Заставка первого запуска под бит (СТАРТ → G A Z game → меню на 0:05), флаг «уже видел».
- Музыкальный плеер: один трек, винил на полке, пауза, ползунки «Музыка» и «Звуки» с сохранением.
- Звуковые эффекты на всё (Web Audio).
- Скины коробки: лампочка в углу переключает 5 оформлений (Классика, Песок, Лёд, West, Барокко), выбор сохраняется; то же в «Обои».
- Билет «Продолжим: <игра>» — продолжение последней игры (показывать реальную последнюю).
- Календарь «Батл дня» + серия «7 дней подряд» (стрик по дням).
- Кнопка «Мне скучно» (DANGER) — случайная игра/задание.
- Кубики на полке — случайный выбор игры; «Правила» — вкладыш с правилами.

**«Чем займёмся?»**
- Анимации открытия коробки (5 вариантов по скину) и разделов (Тусовка, Дневник, $HOW).
- Кейс VIP открывается → экран VIP. «Коллекция / альбом карт» (сыгранные карты). «Предложи своё» → ссылка на Telegram.

**Разделы**
- Тусовка: 3 колоды с числом игроков (Для своих от 2, Банда в сборе от 4, Без тормозов — VIP/замок).
- Дневник: 3 подраздела — Ты в розыске (весёлые тесты), Психо (психотесты), Глубже (VIP: «Сравнись с другом», «Пазл личности»). Закладки «Нарцисс/Тень/Эго» — пока декор.
- «Наугад» (кубики в шапке колоды) — случайная карта колоды.
- Замки «скоро» на закрытых картах, бейджи «всегда бесплатно».

**GAZ GAME $HOW — целый новый раздел (квиз)**
- Режимы Соло / Вдвоём / Компания.
- «Вопрос дня» (общий на всех, обновляется в 00:00, % правильных ответов).
- Категории-вселенные: Кино, Музыка, Общее, Суд, Загадки, Супер-квиз.
- Механика вопроса: таймер 15 с, подсказки (50:50, «спроси зал», «уверен ×2» — НЕ называть «ставкой»), очки, итог.
- «Суд над героем»: голосование ВИНОВЕН / ОПРАВДАН.
- Супер-квиз — лестница сумм как в «Кто хочет стать миллионером».
- Вопросы в макете демо — банк вопросов сделать отдельным файлом данных, чтобы пополнять.

**VIP**
- Экран-витрина с перечнем, что открывает VIP, кнопка «Стать VIP» (оплату пока заглушкой, если её нет).

**Магазины (App Store / Google Play)**
- Нигде нет слов «ставка»: переименовать «СТАВКИ СДЕЛАНЫ» → «ИГРА НАЧАЛАСЬ», «НАГРАДА $500» → «НАГРАДА: УВАЖЕНИЕ».
- Строка в «О приложении»: «Без ставок, денег и выигрышей. Казино-оформление — только стиль. Мы против азартных игр».
- Бутылка в VIP-кейсе — без «BRUT», безалкогольная.

Порядок: сначала дизайн существующих экранов, затем новые функции по одной, каждую — отдельным коммитом и с моего «ок».

2. Изучи стек и структуру этого проекта (фреймворк, роутинг, где компоненты, где стили).
3. Составь и покажи мне таблицу соответствия: «экран макета → экран/компонент проекта → что меняется». Отдельно перечисли экраны проекта, которых нет в макете (их оформить по общей системе, см. ниже), и элементы макета, которым нет пары в проекте.
4. Жди моего «ок».

## Этап 1 — дизайн-система
Создай общий слой (токены + базовые компоненты):
- **Шрифты** (Google Fonts): Playfair Display, Marck Script, Kelly Slab, Rubik Glitch, Rubik Mono One, Bungee Inline, Bungee, Unbounded, Manrope, IBM Plex Mono, Comfortaa, Bad Script, Rye, Roboto Slab.
- **Цвета/градиенты**: золото `#8a6420 → #f6e3a1 → #b8913f → #fff1c4 → #9c7426`, сукно `#1a7a4e/#0b4a2e/#031a10`, дерево стола, бумага `#fbf6e8/#f3ead6`, оранжевый GAZ `#ff7a1a/#e2470f`.
- **Физические кнопки** (как в макете): «назад» = деревянная табличка с двумя гвоздями; продолжение игры = театральный билет с корешком «оторви»; режимы = бумажные билеты ADMIT ONE/TWO/ALL; основные действия = объёмные жетоны; подписи = деревянные/картонные бирки. Плоских веб-кнопок не должно остаться.
- **Тени, бумага, скотч, гвозди, золото** — сделай переиспользуемыми.

## Этап 2 — экраны (по одному, сверяясь с `_design/etalon`)
1. Заставка первого запуска: чёрный экран → кнопка «СТАРТ» → трек с начала → G, A, Z влетают, «game» печатается, полоса → вспышка и переход в главное меню ровно на 0:05 трека (синхрон по `audio.currentTime`). Показывается один раз (флаг в localStorage).
2. Главный стол: коробка GAZ GAME (скины коробки через лампочку), полка с инструментами «музыка/кубики/правила/обои», билет «Продолжим: <последняя игра>», календарь «Батл дня», кнопка «Мне скучно» с пульсацией и «НЕ НАЖИМАЙ», VIP-карта.
3. Открытие коробки (анимация крышки + вылет) и экран «Чем займёмся?» (лоток с 4 отсеками, подложки, кейс VIP, «Предложи своё», коллекция).
4. Разделы: Тусовка (казино-стол, рулетка, 3 колоды, «Без тормозов» с ледяными трещинами), Романтика, Дневник (книга, кармашки, кометы, стол с предметами), Ты в розыске / Психо / Глубже, GAZ GAME $HOW (ретро-ТВ, студия, билеты, диорамы категорий, ТВ-плашка «Вопрос дня»), VIP (кейс открывается, комната с канатом).
5. Карточки игр и тестов в каждом разделе — оформление как в макете; содержимое и логика — из проекта.
6. Экраны проекта, которых нет в макете (сама игра, вопросы, итоги и т.п.), — оформить в стиле своего раздела, используя ту же систему. Покажи мне их скриншоты перед финалом.

## Этап 3 — анимации, звук, музыка
- Анимации открытия разделов: Тусовка (рулетка сверху + колода раскладывается в 3 колоды), Дневник (3D-книга открывается, карточки заезжают в кармашки), $HOW (наезд камеры в экран + прожекторы). Всё уважает `prefers-reduced-motion`.
- Музыка: один трек `bg.mp3`, играет везде, loop. Кнопка-винил на полке: пауза + ползунки «Музыка» и «Звуки», значения сохраняются. Громкость делать через Web Audio GainNode (на iOS `audio.volume` не работает).
- Звуковые эффекты (Web Audio, синтез — как в макете): нажатия, перемешивание, фишки, страницы, щелчки и т.д.

## Проверка
- После каждого этапа: прогон всех игр/тестов от начала до итогов — работают как до изменений.
- Скриншоты 390×844 каждого экрана рядом с `_design/etalon/*.png` — расхождения перечисли и исправь.
- Проверка на iPhone (Safari) и Android (Chrome): шрифты, громкость, анимации, отсутствие горизонтального скролла.
- Производительность: анимации на `transform/opacity`, без лагов на среднем телефоне.

Работай поэтапно, после каждого этапа — короткий отчёт и скриншоты.
