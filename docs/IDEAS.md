# Идеи

Копилка идей. В MVP их не реализуем: если хочется добавить функцию сверх плана, она записывается сюда.

## Продукт

- Связанные тесты и игры
- Совместимость из двух соло-тестов
- «Насколько хорошо вы знаете друг друга» *(вошла в MVP)*
- «Угадай ответ» для друзей
- Карта компании
- Горячий стул
- Генератор свиданий по городу и языку любви
- Вопрос дня для пар
- Карточки для сторис *(базовая версия вошла в MVP)*
- Кнопка «Глубже 💎» *(вошла в MVP как замер спроса)*
- Стрики
- Шкала «насколько ты себя знаешь»
- Ачивки как на PlayStation («Убийца», «Отчаянный»), прогресс «GAZ пройден на 37%»
- Истории и делёжка опытом
- Комнаты по ссылке (создание — по подписке, гости бесплатно)
- Дуэль тестов
- Тест «со временем»
- «Разговор по душам» как режим «Глубоко»
- Раздел «Для друзей»
- Календарь свиданий с фото
- Партнёрства с заведениями
- ИИ-мыслители в Ultimate

## Технические идеи (появились при разработке MVP)

- Офлайн-режим PWA (service worker): игры работают без интернета на тусовке.
- В Telegram делиться карточкой через `WebApp.shareToStory`. Для этого картинку нужно сначала загрузить на сервер: Telegram требует публичную ссылку.
- Запоминать имена игроков между партиями (удобно для «Кто из компании?»).
- В «Правде или действии» показывать, чей сейчас ход.
- Проверка контента в CI (GitHub Actions): `npm run check` на каждый push.
- Своя веб-аналитика вместо Vercel: custom events в Vercel доступны только на платном тарифе Pro.
