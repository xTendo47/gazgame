# Как добавлять контент (без программирования)

Весь контент GAZ Game — это текстовые файлы в формате JSON в папке `packages/content/data/`:

```
packages/content/data/
├── tests/   ← тесты: один файл = один тест
├── games/   ← игры: один файл = одна игра
└── schema/  ← «правила» для редактора (не трогать, генерируются автоматически)
```

**Новый файл появляется в приложении сам.** Код менять не нужно.

> Совет: открывай файлы в **VS Code**. Благодаря строчке `"$schema"` в начале файла редактор подсказывает названия полей (`Ctrl+Пробел`) и подчёркивает ошибки красным.

## Добавить тест: 4 шага

1. Скопируй `packages/content/data/tests/temperament.json` и назови файл по-новому, например `stress.json`.
2. Поменяй `id` и `slug` на уникальное слово латиницей: `"stress"`. Это слово попадёт в адрес страницы: `/test/stress`.
3. Впиши свои вопросы, варианты ответов и результаты.
4. Проверь файл командой (из корня проекта):
   ```powershell
   npm run content:check
   ```
   Если всё хорошо, появится `✅ Контент в порядке`. Если нет, будет указан файл и место ошибки.

Запусти `npm run dev` и открой раздел: тест уже там.

## Пример теста

```json
{
  "$schema": "../schema/test.schema.json",
  "_note": "Любая заметка для себя — на приложение не влияет",
  "id": "stress",
  "slug": "stress",
  "kind": "test",
  "status": "draft",
  "title": "Как ты справляешься со стрессом",
  "description": "3 вопроса — и ты знаешь свою суперсилу.",
  "emoji": "🧘",
  "sections": ["solo"],
  "tier": "free",
  "ageRating": "all",
  "players": { "min": 1, "max": 1 },
  "durationMin": 2,
  "tags": ["о себе"],
  "related": ["temperament"],
  "scoring": "types",

  "questions": [
    {
      "text": "Завтра экзамен. Ты:",
      "options": [
        { "text": "Составляю план", "type": "planner" },
        { "text": "Зову друзей готовиться вместе", "type": "social" }
      ]
    }
  ],

  "results": [
    {
      "id": "planner",
      "title": "Стратег",
      "emoji": "🗺️",
      "text": "Бесплатная часть результата — видна всем.",
      "deepTeaser": { "tier": "premium", "text": "Начало закрытого разбора…" }
    },
    {
      "id": "social",
      "title": "Командный игрок",
      "emoji": "🤝",
      "text": "Бесплатная часть результата.",
      "deepTeaser": { "tier": "premium", "text": "Начало закрытого разбора…" }
    }
  ]
}
```

### Как считается результат

- У каждого варианта ответа есть `"type"` — id результата, которому этот ответ даёт +1 балл.
- Побеждает результат с наибольшим количеством баллов. При ничьей побеждает тот, что выше в списке `results`.
- Продвинутый вариант: `"scores": { "planner": 2, "social": 1 }` даёт разные баллы нескольким результатам сразу.
- `deepTeaser` — закрытая «глубокая» часть. Пользователь видит её начало и кнопку «Глубже 💎».

### Расширенный формат (пример — `data/tests/temperament.json`)

- `scoring` можно записать объектом: `{ "type": "types", "types": [...], "tieBreak": {...}, "blend": {...} }`.
  - `types` — порядок типов. Он решает ничью, если всё остальное равно.
  - `tieBreak.lastQuestions` — id вопросов (у вопросов тогда нужен `"id"`). При равных баллах побеждает тот, кто набрал больше в этих вопросах.
  - `blend.maxGap` — если второй тип отстал не больше чем на столько баллов, результат смешанный: «Холерик с нотками меланхолика». Тексты «ноток» — в `blendNotes` (ключ — id результата).
  - `rule` — описание правила для себя, на подсчёт не влияет.
- В результате вместо `text` можно писать `paragraphs` (абзацы), а также `subtitle`, `strengths` (плашки), `watchOut`, `tip`, `shareText` (подпись при «Поделиться»).
- Вместо `deepTeaser` у каждого результата — один блок `upsell` на весь тест: кнопка `button` ведёт на экран, где `premium` — главный вариант, а `supreme` — мелкой строкой.
- `intro` показывается перед стартом, `disclaimer` — мелко под результатом.

## Добавить игру

Скопируй похожую игру из `data/games/` и поменяй текст. Механика (`mechanic`) определяет, как в неё играют:

| `mechanic` | Пример | Что в карточках |
|---|---|---|
| `deck` | «Я никогда не…» | `text` |
| `deck` + `cardTypes` | «Правда или действие» | `text` и `type` (`truth` или `dare`) |
| `vote` | «Кто из компании?» | `text` (вопрос) и `award` (звание победителю раунда) |
| `guess-partner` | «Насколько хорошо вы знаете друг друга» | `text` и `options` (2–6 вариантов). А у игры — `ranks` (звания по проценту) |

**Колоды (`decks`)** — это режимы игры. У каждой колоды свой уровень:

```json
"decks": [
  { "id": "fun",  "title": "Весело",  "emoji": "😜", "tier": "free",    "cards": [ … ] },
  { "id": "deep", "title": "Глубоко", "emoji": "🌊", "tier": "premium", "cards": [ … ] }
]
```

Колода с `"tier": "premium"` показывается с замком: нажатие ведёт на «Глубже 💎».

## Все поля

| Поле | Обязательно | Что это |
|---|---|---|
| `id` | да | Уникальное имя латиницей (`love-languages`). **Не меняй после публикации**: по нему хранится прогресс и считается аналитика |
| `slug` | да | Часть адреса страницы. Обычно совпадает с `id` |
| `kind` | да | `"test"` или `"game"` |
| `status` | нет | `"draft"` (черновик, со значком) или `"published"`. По умолчанию `draft` |
| `title`, `description`, `emoji` | да | Название, описание, эмодзи |
| `sections` | да | Разделы: `["solo"]`, `["pairs"]`, `["company"]` или несколько: `["solo", "pairs"]` |
| `tier` | нет | `"free"`, `"premium"`, `"supreme"`. По умолчанию `free` |
| `ageRating` | нет | `"all"`, `"16+"`, `"18+"`. **18+ в приложении сейчас не показывается** |
| `players` | да | `{ "min": 1, "max": 1 }` — сколько игроков |
| `durationMin` | да | Примерная длительность в минутах |
| `tags` | нет | Метки, например `["о себе"]` |
| `related` | нет | `id` связанных тестов и игр для блока «Связанное» |
| `_note` | нет | Заметка для себя |

## Частые ошибки

| Сообщение | Что сделать |
|---|---|
| `файл не читается как JSON` | Лишняя или пропущенная запятая, либо кавычки не те. После последнего элемента списка запятой быть не должно. Кавычки только прямые `"`, не «ёлочки» (ёлочки можно использовать **внутри** текста) |
| `Нераспознанный ключ: "titel"` | Опечатка в названии поля |
| `нет результата с id "..."` | `type` у ответа не совпадает ни с одним `id` в `results` |
| `в related указан "...", но такого теста или игры нет` | Проверь `id` в `related` |
| `id "..." используется в 2 файлах` | Скопировал файл, но забыл поменять `id` |

## Черновики

Весь стартовый контент — **временные заглушки** со статусом `"draft"` и пометкой `[черновик]` в тексте. Когда впишешь настоящий текст, поставь `"status": "published"`.

Чтобы скрыть все черновики на сайте, запусти его с переменной `GAZ_HIDE_DRAFTS=1`.

## Для разработчика: поменять схему

Схемы описаны в `packages/content/src/schema.ts`. После изменения обнови подсказки для VS Code:

```powershell
npm run schema --workspace=@gazgame/content
```
