# apps/ultimate — GAZ Ultimate «Становление» (зарезервировано)

В будущем это **отдельное приложение**: мыслители (ИИ-персонажи), практики, дневник и цели.

Сейчас внутри GAZ есть только тизер: экран `/ultimate` («Готовим кое-что большое. Скоро.»).

## Что переиспользуем

- `packages/content`: формат контента (практики можно описывать как JSON).
- `packages/engine`: прогресс, тиры, результаты тестов как контекст.
- `packages/ui`: дизайн-система (или её вариант для Ultimate).
- `packages/agents`: персонажи, обязательные правила безопасности, лимиты.

Порядок запуска — в `docs/ROADMAP.md` (шаг 6).
