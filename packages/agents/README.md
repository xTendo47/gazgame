# @gazgame/agents (зарезервировано)

Пакет для будущих ИИ-персонажей **Ultimate** («Становление»): «Фрейд», «Сократ», «Марк Аврелий» и другие.

**Сейчас здесь только типы, правила и сбор контекста.** Вызовов моделей и API-ключей здесь нет и не будет:
они появятся только на сервере (`apps/api`), чтобы ключи не попали в браузер или бота.

## Как устроен персонаж

Персонаж — это файл с характером и правилами (`personas/<id>.json`, тип `Persona`):

```json
{
  "id": "socrates",
  "name": "Сократ",
  "emoji": "🏛️",
  "inspiredBy": "Сократ, древнегреческий философ",
  "tier": "premium",
  "character": "Спокойный, ироничный. Почти не даёт ответов — задаёт вопросы, помогая дойти до сути самому.",
  "abilities": ["задаёт уточняющие вопросы", "разбирает убеждения", "предлагает вопрос дня"],
  "rules": ["Не читай лекций длиннее трёх предложений"],
  "status": "draft"
}
```

## Обязательные правила (`MANDATORY_RULES`)

Сервер добавляет их к **каждому** персонажу, и персонаж не может их отменить:

1. Агент честно говорит, что он **ИИ в стиле персонажа**, а не реальный человек.
2. Агент **не врач**: не ставит диагнозы и не назначает лечение.
3. **Кризисный протокол.** При сигналах самоповреждения, суицида или насилия агент выходит из роли, поддерживает и направляет к живой помощи (`CRISIS_RESOURCES`). Номера перед запуском нужно проверить.
4. Аудитория 16–25 и может включать несовершеннолетних, поэтому **никакого 18+** и романтических ролевых игр.
5. Агент не собирает лишние личные данные.

## Контекст и данные

- Агент получает контекст **только из результатов тестов** через `engine` (`buildAgentContext`).
- **Лимиты сообщений** зависят от тарифа (`DEFAULT_MESSAGE_LIMITS`), а считает их сервер.
- **Личные переписки — чувствительные данные.** Нужно учесть 152-ФЗ: хранить на серверах в РФ, получать согласие на обработку, давать возможность удалить переписку, минимизировать срок хранения и не использовать переписки для обучения без явного согласия.

## Границы

- Зависит от `@gazgame/content` и `@gazgame/engine`.
- React, Next.js и UI запрещены (правило ESLint).
- Импортировать в `apps/web` можно только типы. Вызовы делает `apps/api`.
